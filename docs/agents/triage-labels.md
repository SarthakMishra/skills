# Triage labels

Use these labels when triaging GitHub issues. The role names used by installed
triage skills map directly to the same labels here.

| Label             | Meaning                                                    |
| ----------------- | ---------------------------------------------------------- |
| `needs-triage`    | A maintainer needs to evaluate the issue.                  |
| `needs-info`      | The reporter needs to provide more information.            |
| `ready-for-agent` | The work is specified and ready for an agent to implement. |
| `ready-for-human` | The work requires human implementation.                    |
| `wontfix`         | The issue will not be acted on.                            |

For example, an instruction to apply the "AFK-ready" label means `ready-for-agent`.
